# 💉 DiaDecode - Diabetes Prediction System

**DiaDecode** is a Python-based machine learning project that predicts the likelihood of diabetes using medical data.  
It helps users identify risk levels based on key health indicators through a clean and efficient prediction model.

---

## 🚀 Features

- 🧠 Predicts diabetes likelihood from health data  
- 📊 Uses a trained machine learning model  
- ⚙️ Data preprocessing for clean input  
- 💾 Simple and efficient Python implementation  
- 🧩 Easy to modify and integrate into other projects  

---

## 🧰 Technologies Used

- **Language:** Python 3  
- **Libraries:** pandas, numpy, scikit-learn, joblib  

---
## 📋 Usage

- Input health-related data (like glucose, BMI, age, etc.).

- The model preprocesses and analyzes the data.

- The result shows whether the user is at risk for diabetes.

---

## 🧠 Model

- Trained on a diabetes dataset with features such as:

- Glucose level

- BMI

- Insulin

- Blood pressure

- Age

---

The model predicts diabetes risk using classification algorithms from scikit-learn.
